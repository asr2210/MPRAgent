# Experiment 001 — SynthSeqs topic-weighted

## What I did
Sampled 50,000 sequences from Meuleman SynthSeqs (curated 160k 200bp DHS
sequences, 10k per NMF component). Sampling weights = natural NMF
component frequency in the full 3.59M DHS index (e.g., Primitive/embryonic
17.4%, Stromal A 1.6%).

Designed to mirror the `dhs_topic` baseline strategy described in the
informed instructions (eval_01 = 0.7232 there).

## What happened
- eval_01 mean_r = **0.1319**
- All evals in 0.06–0.13 range
- K562 = 0.029 (very low), HepG2 = 0.171, SK-N-SH = 0.196
- Runtime: ~28s eval, ~57s total

## Critical observation
**The absolute scores here are FAR below the `dhs_topic` 0.7232 reported in
the informed instructions** — and instead match the `strategies/v06.md`
baselines (random_uniform = 0.1158, dirichlet_composition = 0.1383, max).

Conclusion: the prepare.py in this run is the **v06 (weak-model) pipeline**.
The informed-instructions tables (Tables 1–3, 0.6–0.8 scores) were
generated by a different, stronger pipeline and are not directly
comparable. My real comparison set is the v06 strategies table:
| baseline             | eval_01 |
|----------------------|---------|
| dirichlet_composition | 0.1383 |
| gc_sweep             | 0.1191 |
| gc_50                | 0.1180 |
| random_uniform       | 0.1158 |
| at_rich              | 0.1062 |
| gc_rich              | 0.0589 |
| homopolymer_rich     | 0.0582 |
| alternating_ry       | 0.0333 |
| dinuc_repeat         | 0.0221 |

My synthseqs result (0.1319) is *between* random_uniform and dirichlet —
real DHS sequences underperform dirichlet-sampled synthetic.

## What this means for theory
1. The model in v06 prepare.py is weak (likely linear / k-mer-based).
   With a weak model, **per-sequence sequence diversity** matters more
   than biological realism: each sequence should provide an independent
   training signal.
2. Real DHS sequences are correlated (similar GC, similar motif content
   within a topic) — so 50k real sequences provide less independent
   signal than 50k dirichlet-sampled synthetic sequences.
3. The "natural" frequency weighting of topics did NOT help here
   (predictably — natural distribution is biased toward common topics,
   reducing within-library diversity).
