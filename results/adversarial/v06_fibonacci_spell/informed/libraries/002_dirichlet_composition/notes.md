# Experiment 002 — Dirichlet composition (replica of v06 best baseline)

## What I did
50,000 sequences, each generated by:
1. Draw p ~ Dirichlet(0.5, 0.5, 0.5, 0.5) → per-sequence base frequencies
2. Sample 200 bases iid from Multinomial(p)

## Result
- eval_01 = **0.1395** (vs v06 baseline 0.1383 — within 0.002, well-calibrated)
- Beats exp 001 synthseqs (0.1319) by 0.008
- K562 = 0.047 (best so far), HepG2 = 0.170, SK-N-SH = 0.202
- Runtime: 72s total

## Interpretation
Replication confirms the v06 baseline result. My prepare.py matches the
v06 evaluator. The 0.008 gap between dirichlet (synthetic, diverse) and
synthseqs (real DHS) is consistent across single seeds.

Per-cell-type: K562 improves substantially (0.029 → 0.047) with dirichlet vs
DHS. K562 may be especially sensitive to library diversity.

## Theory update
**Confirmed**: diverse synthetic > real DHS under this weak-model evaluator.
The lever is composition diversity. Dirichlet wins because:
- Each sequence has unique base frequencies → unique 1-mer signal
- Sequences span a wide range of (pA, pC, pG, pT) tuples
- No biological clustering, so each sequence is an independent
  observation for the model
